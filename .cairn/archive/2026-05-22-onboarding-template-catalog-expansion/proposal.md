## Why

Gap 1 is broader onboarding polish. Cairn has a first template catalog, but first-use UX still needs more concrete profiles so operators do not have to translate generic guidance into docs-only or evidence-heavy repositories.

## What Changes

- Add reviewed onboarding templates for docs-only lifecycle use and release-evidence workflows.
- Keep templates preview-first and quickstart-only: no accepted specs, network, signing, or remote publishing.
- Update README examples to show the broader template catalog.

## Impact

- **Files**: Template catalog, CLI tests, README/docs quickstart examples.
- **Testing**: Catalog/list coverage and apply preview/execution coverage for the new profiles.
